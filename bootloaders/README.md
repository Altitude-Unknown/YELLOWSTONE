# YELLOWSTONE bootloader

`bootloader-yellowstone-v1.0.0.bin` is the
[Altitude SAMD21 Bootloader](https://github.com/Altitude-Unknown/Altitude-SAMD21-Bootloader)
1.0.0 (MIT), written for Altitude Unknown's SAMD21 boards: Arduino uploads over
USB and a UF2 drag-and-drop drive named `YSTONEBOOT`. USB ID: 1209:A5C2.

Install it with an Atmel-ICE and the
[Altitude SAMD21 Bootloader Flasher](https://github.com/Altitude-Unknown/SAMD21-Bootloader-Flasher).
Double-tap RESET to enter the bootloader afterwards.
