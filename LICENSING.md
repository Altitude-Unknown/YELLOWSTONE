## USB ID

YELLOWSTONE uses USB ID 1209:A5C2 from [pid.codes](https://pid.codes), which
assigns IDs to open-source hardware. Its bootloader is the
[Altitude SAMD21 Bootloader](https://github.com/Altitude-Unknown/Altitude-SAMD21-Bootloader) (MIT).
